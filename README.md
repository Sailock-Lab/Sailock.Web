## About
Sailock.Web is the official website of the Sailock project.

It provides:
- Downloads
- Documentation
- Tutorials
- Release notes
- Community resources
- Project information

## Tech Stack
- Next.js
- React
- TypeScript
- CSS
- Tabler Icons

## Development

Install dependencies:
```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:
```bash
npm run build
```
