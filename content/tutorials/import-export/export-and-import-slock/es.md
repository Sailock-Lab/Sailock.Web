Un archivo `.slock` es una **copia cifrada de tu bóveda**. Sirve para guardar una copia de seguridad, pasarte a un móvil u ordenador nuevo, o compartir datos entre Sailock para Windows y Sailock para Android.

## Cómo está protegido

Al exportar eliges una **contraseña para el archivo**. Puede ser distinta de tu contraseña maestra. Sin ella el archivo no se puede abrir, así que guárdala bien.

## Exportar una copia

1. Abre los ajustes y elige la opción de exportar.
2. Elige una contraseña para el archivo y repítela.
3. Elige dónde guardar el archivo `.slock`.

> **Consejo:** guarda una copia fuera de tu dispositivo (un disco externo o tu propio almacenamiento en la nube). El archivo está cifrado, pero solo te sirve si puedes llegar a él cuando lo necesites.

## Importar una copia

1. Abre los ajustes y elige la opción de importar.
2. Selecciona el archivo `.slock`.
3. Escribe la contraseña que elegiste al exportarlo.

Los registros que ya existen en tu bóveda no se duplican. Los nuevos se añaden.

## Windows y Android

Las dos aplicaciones usan el mismo formato. Si usas una versión anterior de Sailock para Windows (previa a la 2.3.2), exporta desde Android con la opción para versiones antiguas de Windows: la copia conserva tus registros, pero no las carpetas, etiquetas, categorías ni plantillas propias.

## Cambiar de dispositivo

1. En el dispositivo antiguo, exporta una copia `.slock`.
2. Copia el archivo al dispositivo nuevo (cable, nube o la vía que prefieras).
3. En el dispositivo nuevo, instala Sailock, crea una bóveda e importa el archivo.
